# ミーム図鑑

カメラの前でミームのポーズをとると、そのミームの動画と音声が流れるプログラムです。体の動きは MediaPipe の姿勢推定で、物は YOLO の物体検出で見分けます。

## 反応するもの

| 名前 | きっかけ | 判定のしかた |
|---|---|---|
| 夜の踊り子 | 両手を肩より上げ、左右の手を何度も交差させる | 直近10回の判定で、手の左右が2回以上入れ替わる |
| スキューバ | 片手を顔の前に上げる | 手首が両肩の間にあり、手の高さが鼻と肩の間にある |
| HAPPY HAPPY HAPPY | 両手を上げて跳ねる | 両手首が両肩より上で、鼻の高さが上下に動く |
| シバコ | 「シバコ」をカメラに映す | 専用に学習した YOLO モデルが信頼度 0.9 より高く検出する |

ポーズをやめると動画と音声は止まります。別のポーズに変えると、新しいほうに切り替わります。
※素材は各自用意しました。著作権の関係でGitHubには載せていません。

## 準備

```powershell
python -m pip install opencv-python mediapipe ultralytics pygame
```

モデル（`pose_landmarker.task`、`model/shibako.pt`）と、動画・音声（`video/`、`sound/`）はこのフォルダに入っています。

## 実行

```powershell
python main.py
```

カメラ（ID 0）の映像に骨格を重ねたウィンドウが開きます。ESC キーで終了します。

## 仕組み

```text
カメラ ┬→ 姿勢推定（毎秒15回）→ ポーズ判定（毎秒5回）┬→ 動画再生（別プロセス）
       └→ 物体検出（5秒に1回まで）──────────────────┴→ 音声再生（別プロセス）
```

動画と音声は別のプロセスで再生します。カメラの処理と分けることで、再生中もポーズの判定が止まりません。メインのプロセスからはキューで「再生」「停止」「終了」を送ります。

| ファイル | 役割 |
|---|---|
| `main.py` | カメラの読み込みと、再生用プロセスの起動 |
| `pose_detect.py` | 姿勢推定と骨格の描画 |
| `gesture.py` | ポーズごとの判定と、再生・停止の指示 |
| `object_detect.py` | YOLO で物を検出 |
| `play_video.py` | 動画を再生するプロセス（OpenCV） |
| `play_sound.py` | 音声を再生するプロセス（pygame） |

### ポーズを増やす

`gesture.py` に `Gesture` を継承したクラスを作り、`GestureManager` の `self.gestures` に加えます。クラスには次の4つが必要です。

- `self.history`：判定に使う過去の値（`deque(maxlen=フレーム数)`）
- `self.detected`：検知したら `True`
- `self.video_file`、`self.sound_file`：流す動画と音声のパス（なければ `""`）
- `update(landmarks)`：毎回の姿勢から `history` を更新し、`detected` を決めるメソッド

書き方の例として、`Jump` クラス（ジャンプの判定）が入っています。今は `self.gestures` に入れていないので反応しません。
